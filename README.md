# Taylor's SkillSwap

Taylor's SkillSwap is a peer skill-sharing event management web application developed for ITS64504 Web Application Programming.

## Technologies
- HTML
- CSS
- PHP
- MySQL
- PDO

## Main Features
- Register and login
- Browse and search sessions
- Join sessions
- Create, edit and delete sessions
- View participants
- My Sessions
- Profile management

## Live Website
https://taylors-skillswap.free.nf

## Database Setup
Import the provided SQL database and update the database settings in `pdo.php`.
